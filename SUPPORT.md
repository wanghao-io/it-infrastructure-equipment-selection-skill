# Support

Choose the channel that matches the request:

| Request | Channel |
|---|---|
| Usage, architecture, sizing, or workflow question | [GitHub Discussions](https://github.com/wanghao-io/it-infrastructure-equipment-selection-skill/discussions) |
| Reproducible defect | [Bug report](https://github.com/wanghao-io/it-infrastructure-equipment-selection-skill/issues/new?template=bug.yml) |
| Feature or workflow proposal | [Feature request](https://github.com/wanghao-io/it-infrastructure-equipment-selection-skill/issues/new?template=feature.yml) |
| Documentation gap | [Documentation report](https://github.com/wanghao-io/it-infrastructure-equipment-selection-skill/issues/new?template=documentation.yml) |
| Vulnerability or sensitive data | [Private security report](https://github.com/wanghao-io/it-infrastructure-equipment-selection-skill/security/advisories/new) |

Before asking for support, provide the Skill version, host, sanitized input, expected outcome, actual outcome, and commands already run. Never post credentials, customer names, private quotations, network addresses, or identifiable project data.

This community offers best-effort open-source support. It does not replace engineering review, vendor compatibility confirmation, a procurement quotation, a safety assessment, or a service-level agreement.
