# Changelog

## Unreleased — v1.1.0

Added:

- Requirement-driven vendor/model comparison framework with hard gates and weighted scoring
- `scripts/compare_vendors.py` and comparison templates
- Vendor-neutral tender/RFQ specification generation workflow
- `scripts/generate_tender_spec.py` and example structured input
- Logical network topology generation in Mermaid and Graphviz DOT
- `scripts/generate_topology.py` and topology input example
- Additional anonymized reference designs for enterprise campus, healthcare IT and small data center/server room projects
- Authoritative procurement research workflow for technical evidence, lifecycle, market pricing and comparable transaction records

Changed:

- HCI, domestic/Xinchuang, HA and other specialized architecture patterns are explicitly optional and requirement-driven rather than default recommendations.
- README and Skill task modes now expose comparison, tender, topology and reference-design artifacts only when relevant.
