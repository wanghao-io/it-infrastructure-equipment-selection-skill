# BOM Checklist

采购BOM必须检查隐藏项：

## Server

- CPU
- Memory
- SSD/HDD/NVMe
- RAID/HBA
- NIC
- PSU
- Rail Kit
- Warranty

## Network

- Switch
- Optical Modules
- DAC/AOC
- Fiber
- Licenses

## Security

- Firewall license
- IPS/AV subscription
- VPN license

## Project

- Installation service
- Configuration service
- Maintenance
- Training
