# Storage Sizing Reference

## Principles

Storage selection must consider capacity, performance, reliability and growth.

## Capacity Model

Calculate:

Raw Capacity → Usable Capacity → Protected Capacity

Consider:

- RAID overhead
- Replication factor
- Erasure coding
- Snapshot space
- Backup space
- Growth rate

## Performance

Evaluate:

- IOPS
- Throughput
- Latency
- Read/write ratio
- Database workload

## Checklist

- Do not compare disks only by TB size.
- Confirm SSD/NVMe endurance.
- Confirm backup capacity separately.
